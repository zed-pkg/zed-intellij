# Roadmap

## 0.1 — local workspace insight

- Multi-package discovery.
- Manifest, lockfile, and materialization diagnostics.
- CLI availability probe.
- Tool window, refresh action, and confirmed command execution.
- Unit tests and Plugin Verifier CI.

## 0.2 — canonical CLI diagnostics

- Add `zed inspect --format json --no-network` to `zed-cli`.
- Publish the versioned schema from `zed-interfaces`.
- Replace heuristic checks with canonical CLI evidence where available.
- Add source ranges and editor navigation.

## 0.3 — richer IDE integration

- Gutter and editor annotations for manifest entries.
- Dependency graph view.
- Registry version/update insight with explicit network opt-in.
- Safe quick fixes for dependency add/remove/update operations.
- Project import and language-adapter health checks.

## 1.0 — marketplace release

- Marketplace signing and publishing.
- Compatibility verification across supported IntelliJ builds.
- Privacy disclosure, support policy, and stable diagnostics schema.
